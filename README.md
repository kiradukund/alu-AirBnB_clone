# AirBnB Clone - The Console

## Description

This project implements a command-line interpreter to manage AirBnB objects.

## How to start

```bash
./console.py
```

## How to use

**Interactive mode:**

$ ./console.py
(hbnb) create BaseModel
<id>
(hbnb) quit


**Non-interactive mode:**

$ echo "help" | ./console.py


## Commands

| Command | Usage |
|---------|-------|
| create | create <class> |
| show | show <class> <id> |
| destroy | destroy <class> <id> |
| all | all or all <class> |
| update | update <class> <id> <attr> <value> |
| quit | quit |
